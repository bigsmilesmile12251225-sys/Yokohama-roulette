# 横浜バス旅行 ハーバー争奪ルーレット

横浜バス旅行のお土産(ハーバー)プレゼント企画のための抽選ルーレットです。
iPhoneのSafari(縦画面)で使うことを想定しています。

- `index.html` の1ファイルだけで動きます(外部ライブラリ・通信は不要)
- 入力した名前はどこにも保存されません。ページを閉じると消えます
- 抽選には `crypto.getRandomValues` を使い、偏りが出ないようにしています

---

## 公開方法(GitHub Pages)

1. GitHubのリポジトリで「Settings」→「Pages」を開きます。
2. 「Build and deployment」の「Source」で「Deploy from a branch」を選びます。
3. 「Branch」で `index.html` があるブランチと `/ (root)` を選び、「Save」を押します。
4. 数分後に表示されるURL(`https://<ユーザー名>.github.io/<リポジトリ名>/`)をiPhoneのSafariで開きます。

> 一度ページを開けば、そのタブを閉じない限り通信なしで最後まで使えます。
> 現地の電波が不安なときは、出発前にページを開いておき、タブを閉じずにおいてください。

---

## 使い方

### 1. 名前を貼り付ける

1. メモ帳(メモアプリ)に、参加者の名前を **1行に1名** ずつ書いておきます。
   ```
   参加者A
   参加者B
   参加者C
   ```
2. メモの文字を長押しして「すべてを選択」→「コピー」します。
3. ルーレットの「① 参加者の名前」の欄をタップして、「ペースト」します。
4. 「現在 ◯名」に正しい人数が出ているか確認します。

- 空行や、名前の前後のスペースは自動で無視されます。
- 同じ名前が2回以上あると赤い警告が出て、抽選に進めません。重複している名前を直してください(全角・半角の違いも同じ名前として扱います)。
- 「入力をクリア」で入力欄を空にできます。

### 2. 当選人数を変える

- 「② 当選人数」の「−」「＋」で変更します。初期値は5名です。
- 選べるのは1〜10名で、参加者の人数より多くはできません。
- 抽選を始めたあとは変更できません。変えたいときは「最初からやり直す」を押してください。

### 3. 抽選する

1. 「抽選へ進む」を押すと、ルーレット画面になります。
2. 「スタート」を押すと、ルーレットが回ってだんだん遅くなり、1名に止まります。
3. 「◯人目の当選者」が大きく表示されます。
4. 「次の抽選へ」を押し、もう一度「スタート」を押すと次の人を抽選します。当選した人はルーレットから自動で外れます。
5. 全員が決まったら「当選者一覧を見る」を押すと、一覧が表示されます。

- 回っている間はドラムロールとカチカチ音、当選したときはファンファーレが鳴ります。
- 待っている間・当選表示・一覧では、港をイメージしたゆったりしたBGMが流れます(回転中は止まります)。
- **音が出ないとき**:iPhoneの音量を上げてください。マナーモード(消音スイッチ)がオンだと、iOSのバージョンによっては音が出ないことがあります。

### 4. BGMのオン/オフ

- 最初の画面の「③ BGM」のスイッチで切り替えます(初期値はオン)。
- 抽選画面の「♪ BGM オン/オフ」ボタンでも、いつでも切り替えられます。
- BGMは音声ファイルを使わず、その場で合成しています(オリジナル曲です)。録画モードでは動画にも入ります。

### 5. 最初からやり直す

- 画面下の「最初からやり直す」を押し、確認画面で「OK」を押すと、最初の画面に戻ります。
- 抽選結果と録画した動画は消えます。入力した名前は残るので、そのままもう一度抽選できます。

## 録画モードの使い方(動画を保存する)

ルーレットの映像と効果音を、そのまま動画ファイルにできます。

1. 最初の画面の「④ 録画モード」のスイッチをオンにします。
   - 「この端末では録画モードを使えます(mp4形式)」と出れば使えます。
   - 「対応していません」と出た場合は、下の「iPhoneの画面収録」を使ってください。
2. 「抽選へ進む」→「スタート」を押すと録画が始まります(画面下に「● 録画中」と表示されます)。
3. 全員の抽選が終わり、「当選者一覧を見る」を押すと、一覧を数秒映してから録画が自動で終わります。
4. 「録画が完了しました」の画面が出たら、
   - **「写真に保存・共有する」** → 共有メニューの **「ビデオを保存」** を選ぶと「写真」アプリに保存されます。LINEなどへ直接送ることもできます。
   - うまくいかないときは **「ファイルとしてダウンロード」** を押します。「ファイル」アプリの「ダウンロード」フォルダに保存されます。
5. 画面を閉じたあとも、一覧画面の「動画を保存」から何度でも開けます。

**録画するときの注意**

- 最初のスタートから一覧までを、1本の動画にします。待っている時間もそのまま録画されます。
- 録画されるのはルーレット部分だけです。ボタンは映りません。
- 録画中に他のアプリへ切り替えたり、画面をロックしたりしないでください。動画が途中で止まったり、乱れたりすることがあります。
- 「最初からやり直す」を押すと、録画した動画は消えます。先に保存してください。
- 本番の前に、「参加者A」などの仮の名前で一度録画し、最後まで映像が動いているか確認しておくと安心です。
- iPhone版のChromeも、中身はSafariと同じ仕組みで動いているため、録画の結果はSafariと同じになります。パソコンやAndroidのChromeでは録画モードが使えます。
- **iOS 26のSafariでは、録画の途中で映像が止まり、音声だけになることがあります。** 確実に残したいときは、下の「すっきり表示」と「画面収録」を使ってください。
- 録画中に映像が止まったことを検知すると、画面に「録画の映像が止まった可能性があります」と表示します。

**診断情報(不具合の報告用)**

「録画が完了しました」の画面にある「診断情報」を開くと、録画中の記録(いつ・どの場面で映像が止まったか)が見られます。「診断情報をコピー」でコピーして、不具合の報告に貼り付けてください。名前は含まれません。

## 画面収録向けの「すっきり表示」

iPhoneの「画面収録」で録るときに、ボタンが映らないきれいな動画にするための表示です。

1. 最初の画面の「④ 録画モード」のカードにある **「画面収録向けのすっきり表示」** をオンにします。
2. 下の手順で「画面収録」を始めてから、「抽選へ進む」を押します。
3. 抽選画面ではボタンが消えます。**ルーレットをタップ** すると、スタート・次の抽選へ・当選者一覧へと進みます。
4. **ルーレットを長押し**(約1秒)するとメニューが開きます。BGMのオン/オフ、最初からやり直す、すっきり表示をやめる、などができます。
5. 当選者一覧が出たら、画面収録を停止します。

- 収録した動画の最初と最後に入った操作の様子は、「写真」アプリの「編集」で前後を切り取ると、きれいに仕上がります。
- Safariのアドレスバーを映したくない場合は、Safariの共有ボタンから「ホーム画面に追加」をして、ホーム画面のアイコンから開くと全画面で表示されます(このときは開くときに通信が必要です)。

## iPhoneの「画面収録」の手順(録画モードが使えないとき)

### 準備(はじめて使うときだけ)

- **iOS 18以降**:画面の右上から下にスワイプして「コントロールセンター」を開きます。左上の「＋」をタップして(または何もないところを長押しして)、「コントロールを追加」から「画面収録」を追加します。
- **iOS 17以前**:「設定」→「コントロールセンター」で、「画面収録」の左の「＋」をタップします。

### 収録のしかた

1. ルーレットのページを開いておきます。
2. 画面の右上から下にスワイプして「コントロールセンター」を開きます。
3. 「画面収録」ボタン(◉の形)をタップします。3秒のカウントダウンのあと、収録が始まります。
4. コントロールセンターを閉じて、いつもどおり抽選します。
5. 終わったら、画面上部の赤い表示(またはダイナミックアイランド)をタップし、「停止」を押します。
6. 動画は「写真」アプリに保存されます。

- アプリの効果音も一緒に収録されます(マイクの音は、オフのままなら入りません)。
- 画面収録ボタンを長押しすると、マイクのオン/オフを切り替えられます。

## 名前の取り扱い

- このリポジトリには、参加者の実名を一切書いていません(例はすべて「参加者A」などです)。
- 入力した名前は、端末にもサーバーにも保存しません。ページを閉じると消えます。
