# 横浜バス旅行 ハーバー争奪ルーレット

横浜バス旅行のお土産(ハーバー)プレゼント企画のための抽選ルーレットです。
iPhoneのSafari(縦画面)で使い、iPhoneの「画面収録」で動画に残すことを想定しています。

- `index.html` の1ファイルだけで動きます(外部ライブラリ・通信は不要)
- 入力した名前はどこにも保存されません。ページを閉じると消えます
- 抽選には `crypto.getRandomValues` を使い、偏りが出ないようにしています

---

## 公開方法(GitHub Pages)

1. GitHubのリポジトリで「Settings」→「Pages」を開きます。
2. 「Build and deployment」の「Source」で「Deploy from a branch」を選びます。
3. 「Branch」で `index.html` があるブランチと `/ (root)` を選び、「Save」を押します。
4. 数分後に表示されるURL(`https://<ユーザー名>.github.io/<リポジトリ名>/`)をiPhoneのSafariで開きます。

> 一度ページを開けば、そのタブを閉じない限り通信なしで最後まで使えます。
> 現地の電波が不安なときは、出発前にページを開いておき、タブを閉じずにおいてください。

## 本番の流れ(画面収録しながら使う)

画面はすべて、録画に映っても見栄えがするように作っています。名前を貼り付けるところから収録すると、「エントリー → 抽選 → 当選者一覧」がひと続きの動画になります。

1. **準備**:メモアプリに、参加者の名前を **1行に1名** ずつ書いておきます。
   ```
   参加者A
   参加者B
   参加者C
   ```
2. メモの文字を長押しして「すべてを選択」→「コピー」します。
3. ルーレットのページを開き、**画面収録を始めます**(手順は下の「iPhoneの画面収録の手順」)。
4. **「📋 名前を貼り付け」** を押します。小さく「ペースト」と出たら、それをタップします。
   - 名前が札のように1枚ずつ並び、「エントリー ◯名」に人数が出ます。
5. 当選人数を「−」「＋」で決めます(初期値5名、1〜10名、参加者数まで)。
6. **「抽選スタート!」** を押すと、ルーレット画面になります。
7. **ルーレットをタップ** すると回り始め、だんだん遅くなって1名に止まります。
8. 「◯人目の当選者」が表示されたら、もう一度 **タップ** で次の抽選へ。さらに **タップ** で回します。
   - 当選した人は、次の回のルーレットから自動で外れます。
9. 全員決まったら **タップ** で当選者一覧が表示されます。
10. 画面収録を停止します。動画は「写真」アプリに保存されます。

- 収録した動画の最初と最後に入った操作の様子は、「写真」アプリの「編集」で前後を切り取るときれいに仕上がります。

### 名前の貼り付け・修正

- 空行や、名前の前後のスペースは自動で無視されます。
- 同じ名前が2回以上あると、その札が赤くなり、抽選に進めません(全角・半角の違いも同じ名前として扱います)。**「✎ 編集」** で直してください。
- 「✎ 編集」では入力欄に直接書いたり、貼り付けたりできます(このときはキーボードが映ります)。「すべて消す」で空にできます。
- 「📋 名前を貼り付け」で読み込めないときは、自動で編集画面が開くので、入力欄を長押し →「ペースト」で貼り付けて「決定」を押してください。
- 名前を入れ直したいときは「📋 貼り直す」を押します(今の名前は置き換わります)。

### 音とBGM

- 待っている間・当選表示・一覧では、港をイメージしたゆったりしたBGMが流れます。BGMは音声ファイルを使わず、その場で合成しているオリジナル曲です。
- 回っている間はBGMが止まり、ドラムロールとカチカチ音、当選したときはファンファーレが鳴ります。
- BGMのオン/オフは、最初の画面の「♪ BGM」のスイッチ、または抽選中のメニューで切り替えます。
- **音が出ないとき**:iPhoneの音量を上げてください。マナーモード(消音スイッチ)がオンだと、iOSのバージョンによっては音が出ないことがあります。

### メニュー(やり直し・BGM)

- 抽選画面の右上の小さな **「≡」** を押すか、**ルーレットを長押し**(約1秒)するとメニューが開きます。
- 「♪ BGM オン/オフ」「最初からやり直す」「閉じる」があります。
- 「最初からやり直す」で確認画面の「OK」を押すと、最初の画面に戻ります。抽選結果は消えますが、名前は残るので、そのままもう一度抽選できます。

## iPhoneの「画面収録」の手順

### 準備(はじめて使うときだけ)

- **iOS 18以降**:画面の右上から下にスワイプして「コントロールセンター」を開きます。左上の「＋」をタップして(または何もないところを長押しして)、「コントロールを追加」から「画面収録」を追加します。
- **iOS 17以前**:「設定」→「コントロールセンター」で、「画面収録」の左の「＋」をタップします。

### 収録のしかた

1. ルーレットのページを開いておきます。
2. 画面の右上から下にスワイプして「コントロールセンター」を開きます。
3. 「画面収録」ボタン(◉の形)をタップします。3秒のカウントダウンのあと、収録が始まります。
4. コントロールセンターを閉じて、上の「本番の流れ」のとおりに進めます。
5. 終わったら、画面上部の赤い表示(またはダイナミックアイランド)をタップし、「停止」を押します。
6. 動画は「写真」アプリに保存されます。

- アプリの効果音・BGMも一緒に収録されます(マイクの音は、オフのままなら入りません)。
- 画面収録ボタンを長押しすると、マイクのオン/オフを切り替えられます。
- Safariのアドレスバーを映したくない場合は、Safariの共有ボタンから「ホーム画面に追加」をして、ホーム画面のアイコンから開くと全画面で表示されます(このときは開くときに通信が必要です)。

## 名前の取り扱い

- このリポジトリには、参加者の実名を一切書いていません(例はすべて「参加者A」などです)。
- 入力した名前は、端末にもサーバーにも保存しません。ページを閉じると消えます。
